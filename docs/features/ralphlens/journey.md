# Journey — RalphLens

## Intake to Completion Path

1. **Intake (`/lens-work-intake`)**
   - Capture intent and create durable archive.
   - Initialize lifecycle state (`track: full`, `phase: preplan`).

2. **Discovery (`/preplan`)**
   - Clarify user problem, goals, outcomes, and scope boundaries.
   - Produce product brief/research/adversarial review artifacts.

3. **Planning (`/businessplan` -> `/techplan` -> `/finalizePlan`)**
   - Translate validated outcomes into requirements, architecture, epics/stories, and readiness evidence.

4. **Execution (`/dev`)**
   - Implement scoped stories in target repositories.
   - Capture validation evidence and review outcomes.

5. **Completion (`/complete`)**
   - Verify acceptance criteria, finalize evidence, and close lifecycle.

6. **Post-Completion Governance Routing**
   - `/lens-preflight`
   - `/lens-map-audit`
   - `/lens-ledger-promotion`
   - `/lens-salmon-impact` (if upstream impact exists)
   - `/lens-reporting-snapshot`
